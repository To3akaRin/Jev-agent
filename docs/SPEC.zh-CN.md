# Jev agent 首版规格：Laya 与 Jev 双提供者

状态：开发预览版；代码与构建已实施，真实模型、桌面兼容性及发布分别验收。实时证据以[验证记录](./VALIDATION.md)为准。本规格替代“Jev 仅预留接口”的初版定义。

## 目标与交付

根据当前 macOS 应用、输入框和剪贴板历史，推荐此刻适合粘贴的已有内容，由用户确认后粘贴完整原文。项目名称为 **Jev agent**，目标公开仓库为 `To3akaRin/Jev-agent`。

交付源码、源码构建 `.app`、初始化与检查脚本、自动化测试、冻结评测集、真实验证报告和 GitHub 源码版本。项目 MIT；第三方实现、云端服务及权重保留自己的条款。

英文 README 为默认首页，简体中文版独立提供；采用居中名称、简介和导航，末尾分别链接“简体中文”和“English”。不复制参考项目 Archify 的品牌或指标。原生界面首版使用英文，双语文档不等于界面本地化完成。

目标平台为 Apple Silicon；原生应用部署目标 macOS 14+，MLX 运行兼容性必须独立核验。计划首轮设备为 M2 Max、32 GB、macOS 15.7.7，不把编译通过当作该设备模型已运行。

## 产品边界

### 历史

- 仅记录应用运行期间复制的纯文本，保留链接、代码、多行文本和空白。不导入其他工具历史，不处理图片／文件。
- 最近复制时间超过 72 小时清理；全部历史最多 20,000,000 字节，包含正文、元数据和临时历史写入。模型、依赖和应用不计入。
- 同内容去重更新，完整原文不规范化、不截断；单条超出预算直接跳过。
- 独立记录文件加内存索引，写入前驱逐最旧记录预留空间，同目录原子替换。启动清理临时文件、坏记录及校验失败记录。
- 启动、唤醒、写入、读取候选和定时维护检查有效期。暂停记录、排除来源应用、单条删除、全部清空均可手动控制。
- 明确机密标记和安全字段排除。来源只能使用可观察证据，缺失时标记未知。应用自身为了复制／粘贴写入的内容不再次采集。

### 推荐与粘贴

- 默认快捷键 `⌘⇧V`，允许更改和冲突提示；普通 `⌘V` 保持原状。
- 面板激活前保存目标应用、输入框及可获取的选区。读取应用、Bundle ID、窗口标题、字段标签和有界附近文本；不遍历完整窗口、不截图、不做 OCR。
- 面板展示提供者、状态、候选、完整原文预览和搜索。方向键选择、回车确认、Esc 取消。
- 最近两条加相关项构成最多六条候选，使用英文词、中文双字及格式信号召回，再由模型选择；其余历史可手动搜索。
- 用户开始手选后，迟到的模型结果不能移动选中项。无匹配、异常、权限缺失或超时保留手选，不把基线条目标成模型推荐。
- 粘贴前重新核验目标及可验证的选区，失效则取消；只有确认后的完整原文可以写入剪贴板并触发一次粘贴。禁止自动发送消息、提交表单或执行命令。
- 保留选中原文为当前剪贴板，不延迟恢复旧内容。无法可靠定位目标时只复制。

## 双提供者与数据边界

### 默认本地 Laya

使用 `laya-mlx==0.1.0` 与 `aac6fef/laya-multilingual-mlx`，固定 revision 为 `ba40c87fcb357f1643d04d71323af9cdc3b9e591`。首次显式下载，worker 初始化仅加载本地快照；缺失应报错而不是后台下载。

实际 tokenizer 和 checkpoint 配置约束上下文及问题预算；裁剪仅改变模型摘录，不改变存储正文。MLX 不可协作取消的推理超时后回收进程，避免积累任务。

### Jev 云端

通过 `typesafe-sdk==0.7.0`、异步客户端、`Choice` 和 `system_one()` 调用官方 `https://api.typesafe.ai/v1/systemone`，初始模型 `jev-1.13.0`。模型权限和实际返回版本需要真实探测，不静默改用其他模型。

只在用户显式选择 Jev 并请求推荐时发送当前上下文和候选摘录；不上传全部历史，不在复制事件时后台请求。Jev 模式不要求 MLX 或本地权重，Laya 模式不建立 Jev 连接。提供者失败不会自动切换。

桌面 key 存入 macOS Keychain，CLI 使用 `TYPESAFE_API_KEY`。拒绝读取凭据应显示错误，不应静默使用不同凭据。真实值不进入命令行参数、请求正文、源码、文档、公开报告或构建包。

### 协议和失败

Swift 与 Python 通过版本化 JSON Lines 本地管道通信，不监听端口。请求包括 ID、配置版本、提供者、白名单上下文和候选；结果包括选择、概率、模型、耗时、usage 和错误。详见 [API](../API.md)。

stdout 仅协议，stderr 为日志。候选 ID、类型和概率需要校验；无匹配使用 null 选择和 `none` 概率标签。丢弃旧请求、旧配置及被取消的响应。

交互预算最多 2 秒，Jev SDK 不自动重试；模型加载状态单独展示。准备模型不会阻塞手动列表。异常进程最多自动恢复一次；恢复就绪不能自动重发已经超时的付费请求。日志包含 operation、请求 ID、提供者、完整错误及耗时；Jev 另记录方法、路径、上游地址、HTTP／业务状态和上游请求 ID，未提供的字段不编造。

自动测试至少覆盖：过期边界、容量和原子临时空间、Unicode 去重及搜索、坏文件、输入裁剪、无匹配、非法候选／概率、超时、断连、上游 401/403/422/429/5xx/529、取消和配置变化。测试替身负责可控异常，不向真实服务主动制造故障。

固定验收集至少 60 条，中英文各不少于 30 条，包含姓名、邮箱、地址、链接、多行文字、代码、相似干扰、长文本及无匹配。调参样例与验收集分开。Laya 与 Jev 使用共同整理后的请求，比较最近项和纯检索基线，报告召回、Top-1、Top-3、无匹配识别、错误与超时。超时和失败必须计入总样本，概率不能称为业务准确率。

Jev 首轮合成决策预算最多 120 次，包含冒烟、固定集、重复稳定性和桌面测试。账本持久化、并发加锁、调用前计数；鉴权失败停止后续批次。不通过重试或重置计数绕过限制。

在 Chrome、Safari、TextEdit 使用合成内容测试两个提供者，覆盖权限拒绝／撤销、目标变化、选区变化、取消、重复确认、快速唤起、休眠唤醒和模型进程退出。以目标字段实际内容作为粘贴验收证据。

记录冷加载、预热后推理和完整交互 P50/P95、峰值内存与空闲占用；上游宣传数据不可替代本机测量。CLI 10 秒测量预算不代表两秒产品预算通过。

## 原生交付和完成定义

本项目适用已经确认的原生桌面例外，不使用 Docker Compose。初始化入口为 `bootstrap.sh [laya|jev|both]`；构建 `.app` 使用当前 checkout / `.venv` 的绝对路径，ad-hoc 签名，不内置独立 Python，不提供 Developer ID 公证和自动更新。

初始化、更新、权限和排障命令必须与当前脚本一致，见[中文 README](../README.zh-CN.md)。环境变量同步 `.env.example`；应用不会隐式读取 `.env`。

功能代码、本地检查、模型真实调用、固定评测、桌面验收和 GitHub 发布分别记录。只有以下全部通过，才可以宣称项目完整完成：

- 目标 Mac 上的历史、上下文、双模型、确认粘贴及失败处理真实有效。
- 两种提供者分别完成效果和桌面验收，Laya 下载后离线运行、Jev 断网时手选可用。
- 初始化和构建可复现，测试、lint、文档检查和 CI 通过。
- 英中首页、API、贡献指南、更新日志、配置及第三方说明与实现一致。
- 公开仓库、验收对应远程提交和版本说明已核验，不包含私人历史、权重或真实密钥。

任何缺失权限、真实模型失败或未执行测试必须保留为未完成，不用测试替身或构建成功填充。
