# Product

## Register

product

## Users and purpose

Apple Silicon Mac users filling web forms and editing text. They copy addresses, email, links and code, then need to select the correct original entry for the focused field. The approved workflow is a menu bar utility, a dedicated shortcut, a compact candidate panel and explicit confirmation. English UI and an English README with an equivalent Simplified Chinese README are the first release's language scope.

## Principles

- Make original content easy to inspect before acting.
- Keep regular paste unchanged and never submit a form.
- Show local or cloud provider explicitly; never switch providers silently.
- Keep manual selection usable when models or permissions fail.
- Use familiar macOS controls, keyboard navigation and system accessibility.

## Tone and boundaries

Calm, precise and practical. Follow the approved native utility layout, not a promotional dashboard. No decorative metrics, animations, or invented model-confidence claims. The Archify reference applies to README language navigation only.
