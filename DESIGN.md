# Native interface

The user is moving between a browser form and copied reference text during everyday desk work. Follow the system light/dark appearance so the utility stays consistent with the active desktop.

- Native system text, semantic system colors, one system accent for selected rows and the primary action.
- Compact panel around 660 × 560 points, search at top, target/provider status, candidate list with a readable preview, actions at bottom.
- Standard settings form for provider, key, model, shortcut, pause and excluded apps.
- Loading and failure states inline; manual history remains interactive.
- Keyboard focus, VoiceOver labels, Escape cancellation and no decorative motion.
